# Änderungen

## 0.1.0 — 2026-10-08

Erste öffentliche Version von Lag Check für Windows x64.

- Native Desktop-Oberfläche mit Live-Karten, Verlauf und drei Lag-Markern.
- Einsekunden-Systemmessung und unabhängige optionale Netzwerkproben.
- Verständliche lokale Berichte, Messhistorie und vorsichtige Kategorien.
- Alt-Tab-Hinweis, Prüfung auf unvollständige Daten und Baselines je Ping-Ziel.
- Export per Positivliste, ohne persönliche Identifikatoren oder Rohprotokolle.
- MIT-Lizenz, Dokumentation, Tests und portable Windows-Builds.

Bekannte Grenzen: deutsche UI, IPv4-Ping, keine globalen Hotkeys/Overlays,
keine Spiel-/FPS-Messung, unsignierte EXE, keine automatische Wiederherstellung
abgebrochener Sitzungen. Windows 10/11 vorgesehen; lokale Prüfung auf Windows 11
und CI auf einem Windows-Runner ersetzen keinen Test aller Treiber/Windows-Versionen.
