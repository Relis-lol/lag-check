# Sicherheitsprobleme melden

Bitte keine Zugangsdaten, privaten IPs oder Rohlogs in öffentliche Issues posten.

Wenn GitHub **Report a vulnerability** für dieses Repository anbietet, nutze die
private Sicherheitsmeldung. Andernfalls eröffne nur ein allgemeines Issue mit
der Bitte um einen privaten Kontaktweg, ohne Exploitdetails oder persönliche Daten.
Es gibt keine zugesicherte Reaktionszeit oder bezahlten Support.

Untersucht werden insbesondere unbeabsichtigte Veröffentlichung lokaler Daten,
unsichere Exporte, beliebige Codeausführung beim Lesen lokaler Berichte sowie
Verstöße gegen die dokumentierten Grenzen der passiven Messung.

Die aktuelle Version 0.1.x ist die unterstützte Entwicklungslinie. Alte portable
Versionen aktualisieren sich nicht selbst; Releases manuell prüfen.
